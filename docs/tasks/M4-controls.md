# M4 小阶段：登录失效与暂停控制

状态：本机可控样本验证完成；完整 M4/P0 未完成。
对应验收：C03、C06、D02、D10；报告与系统中断专项留待后续。

## 问题与预期行为

普通业务用例在已登录后意外回到登录表单，应暂停整批，不能刷出产品失败。
已经进入前置准备或业务操作的用例保留 ERROR（已有明确失败则保留 FAILED），显式继续后从下一条开始，不自动重放。
只在认证/输入校验阶段失败且尚未准备业务状态时，允许用户继续后重新认证。
明确包含登录/登出的用例不能将其预期的登录页当成环境故障；本轮只验证意图识别规则，完整业务登录类用例仍需独立验收。

## 本次范围

- 固定只读页面观察识别登录表单，沿用配置域名与账号边界。
- 暂停后刷新管理页面、重新连接事件流，不创建新任务或重复提交。
- 继续后重新观察；停止保留已有通过结果，未完成项取消。
- 可控目标提供可见提交次数及独立的会话失效样本，不修改真实环境。

## 输入与依赖

沿用已配置模型、本机 Chrome、Pi/MCP 和用户启动的热加载服务。
只使用合成 xlsx 与本地 demo 账号；当前无活动任务，不手动启动或重启服务。
本轮不调整已确认的一屏工作区或添加配置 UI。

## 实现与验证

1. 单元/状态契约检查覆盖登录意图、意外登录页、认证前后恢复边界与已有失败保留。
2. 新建已确认的合成批次，在提交后暂停，保持现场，页面刷新并继续，断言提交仅一次。
3. 后续用例开始后再暂停并从页面停止，断言已有 PASSED 保留，其余 CANCELLED。
4. 登录失效样本从真实 UI 跳回登录页，断言整批 PAUSED，当前 ERROR、后续 PENDING；从页面继续后下一条正常执行，第一条不重跑。
5. 保存真实工具、事件、页面截图、结构化摘要；检查脱敏与资源释放，更新计划。
