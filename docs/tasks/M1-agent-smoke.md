# M1：真实 Agent 到浏览器的最小闭环

状态：已完成（2026-10-30，本机可控页面；完整 P0 尚未完成）
对应验收：A01–A06、D06、D07

## 目标

在可控桌面网页上，让真实 Pi SDK 会话通过 MCP 操作可见浏览器，执行一条固定测试用例，并生成可追溯的结构化结果。

## 范围

只实现最小配置加载、SDK/MCP 接通、受控页面操作、步骤证据与结果校验。
不提前实现 Excel 全套导入、完整后台页面、并发、团队账号或新用例生成。
没有可用模型时保留清晰的配置错误，不伪造接通结果。

## 顺序

1. 核实候选 Pi 版本和可安装 Playwright MCP 版本、实际导出与工具清单，再添加精确依赖与 lockfile。
2. 明确模型 ID、工具调用和图像输入能力；不需要在代码中保存用户密钥。
3. 实现独立 agentDir 和明确的工具/Skill 范围，验证不会自动继承个人全局工具。
4. 创建可控页面与一条场景：打开表单、输入、提交、验证文本与字段相对位置。
5. 接入真实 Pi → MCP → headed 浏览器，采集步骤结果、截图和逐项预期验证。
6. 校验缺失证据不得通过；故意改变字段位置后，应得到明确失败。
7. 实测终止与资源释放，记录实际版本和证据；不要自动重启用户服务。

## 完成证据

- 配置与依赖可重复安装，版本与来源明确。
- 实际工具调用对应实际页面变化，而不是模型“打算操作”的文本。
- 同一次执行的用例、步骤、预期和截图能互相定位。
- 通过样本与失败样本都得到正确结果；不稳定或未验证的能力如实记录。
- 文档检查、实际新增的静态/业务检查和浏览器验证分别报告。

M1 完成仍不代表 P0 完成，后续里程碑和真实 Excel/系统验证必须继续完成。
