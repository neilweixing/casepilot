# M4 小阶段：中断、历史与数据清理

状态：已完成本机可控样本验证。
对应验收：D11、D12。Windows 实机验证继续延后。

## 问题与预期行为

退出时应立即保存中断状态，再等待浏览器收尾。异常退出后核实执行锁与工具进程归属；旧进程仍活着时不得篡改其任务或抢占浏览器。恢复历史时保留已确认结果，活动用例中断、未开始项保留，不自动重放。

默认保留被测系统中的测试数据；只有确认后的用例明确要求时才通过 UI 清理。本轮清理目标可恢复，不永久删除用户数据。

## 本次范围

- 新任务锁记录运行 ID 与进程归属，识别可安全回收的残留锁；归属不明或仍有工具存活时保守阻止新任务。
- 正常关闭与独立验收子进程突然退出；验证保存的通过结果、最后操作未知状态、未开始项及历史 API/报告。
- 真实模型与浏览器验证默认保留，以及用例明确要求的 UI 清理。目标提供独立计数与恢复入口，计数接口仅用于验收副作用。
- 不重启用户服务、不新增自动重跑或恢复执行入口，不移动或伪造主工作区历史任务。

## 验证与完成条件

用状态测试覆盖立即持久化、存活归属、残留锁、未知锁及重复恢复。用独立运行子进程做正常关闭/突然退出验收，重开相同数据检查历史和报告，证明没有再次执行业务操作。清理样本须有真实 UI 调用与证据。记录实际命令、资源释放和脱敏结果。

## 完成记录
