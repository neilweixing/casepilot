# 任务：用例集按系统维度管理

状态：已完成（本机实测）
对应里程碑：M4 补充
对应验收：C07（docs/acceptance.md）

## 问题与预期行为

用例集（导入的工作簿）此前与被测系统无关，用例库按导入文件平铺展示；用户希望用例按系统维度管理。本次完成后：每个用例集归属一个系统，用例库按系统分组并支持筛选；确认版本前必须指定所属系统；创建任务时环境必须与用例集属于同一系统；删除系统受用例集引用保护。

## 本次范围

- `ImportDraft` 增加 `systemId`（空串 = 未指定），确认快照自然继承。
- 修订接口支持更新归属；归属变更生成新版本并取消确认。
- 确认门禁：未指定系统拒绝确认。
- 创建任务校验环境与快照系统一致（旧快照无归属保持可用）。
- 删除系统受"系统下还有用例集"引用保护。
- 前端：用例库按系统分组 + 筛选；导入编辑器选择所属系统（可创建新系统）；新建测试页提示环境与用例集系统不一致。

暂不涉及：单条用例级归属、跨系统混合工作簿、已有系统的改名/合并、任务与报告页的系统展示增强。

## 输入与依赖

- 契约 `packages/contracts/src/p0.ts`、服务端 `imports.ts`/`api.ts`/`runs.ts`/`deletion.ts`、前端 `apps/web/src/main.tsx`。
- 系统/环境 UI 已有"创建新系统"交互模式（EnvironmentPage），本次沿用。

## 实现步骤

1. 契约与存储层：`ImportDraft.systemId`，旧记录读取归一化。
2. 服务端门禁与校验：`reviseImport` 归属参数、`confirmImport` 门禁、`RunManager.create` 一致性、`deleteSystem` 引用保护。
3. 测试：确认门禁、无效归属、归属修订、执行一致性、删除保护边界。
4. 前端：分组与筛选、编辑器选择器、新建页校验与提示。
5. 文档：验收项 C07、决策 D28、plan 状态。
