# M3 小阶段：普通字符图片验证码

状态：已完成本机可控样本验证。对应 C04、C06、A05、E08。

## 问题与预期行为

现有 image 配置只有提示中的三次约定，缺少服务端识别/刷新/提交预算；填写凭证后，整页截图会因敏感字段而被拒绝。新增受控验证码图像工具，仅截取可见 img/canvas，确认图像实际发送给模型后才能提交识别值。失败可在有限预算内刷新图片；无法可靠识别或耗尽时暂停整批，不进入业务步骤。

## 本次范围

普通字符图片，配置 image 的认证阶段；不增加滑块、点选或第三方反机器人挑战支持。保持账号密码由已有受控工具填写。重试只能针对认证，不放宽提交不确定或业务步骤的重放约束。

## 验证与完成条件

先验证独立预算单元的边界，再接入真实 MCP 的元素截图、填写及点击。用独立合成页面覆盖正常识别、首次失效后刷新恢复、持续拒绝达到上限和不可读图片；报告各场景实际结果及有限样本成功率。登录失败整批暂停，后续业务不执行。核对图像进入模型请求、凭证不进入截图/事件/报告，检查进程和锁释放。真实验收期间冻结后端代码，不启动或重启用户服务。

真实正常登录、失效刷新、持续拒绝、不可读图片均已验证；补充旧图换 ID 和旧提示保护后，新建刷新回归也通过。8 次可读图片识别均正确，不可读样本 3 次观察、0 提交；两种故障整批暂停，后续业务未开始。
