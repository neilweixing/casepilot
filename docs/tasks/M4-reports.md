# M4 小阶段：报告与离线证据

状态：本机可控样本已验证；完整 P0 未完成。
对应验收：E01–E08。Windows 实机验证按用户要求延后，跨平台支持要求保留。

## 问题与预期行为

现有 HTML 只列出文本证据编号，离线时无法回查工具和观察记录。本轮让页面与导出使用同一统计规则，并将本次注册的证据安全内嵌到单个 HTML。缺失证据明确提示，不能更改原结论或编造根因。

## 本次范围

- 全部结果状态、零分母与 8 通过/1 失败/1 阻塞的统计边界。
- 来源版本、环境、时间、前置条件、步骤、逐项实际结果与可定位的归档证据。
- 文本转义、凭证再次脱敏、路径限制与截图内嵌；不加载外部资源或执行输入中的脚本。
- 使用已有真实执行结果从页面下载，打开独立 HTML 检查统计、截图与证据。
- 不新增模型归因步骤，执行说明与原始观察分开展示，根因未经确认就明确说明。
- 不手动重启用户服务；不改已有运行、步骤、预期或业务结论。

## 视觉方案

沿用 frontend-design 和用户指定的克制暖白风格：纸白 #ffffff、浅灰底 #faf9f6、正文 #292825、次要文字 #706b63、边线 #e4e0d8、强调色 #a45f45。中文正文使用系统无衬线，数字使用系统衬线；不依赖在线字体。左对齐的任务摘要、紧凑统计、用例目录与逐条证据，原始工具内容折叠。导航只使用文档内部锚点，不复制工作台侧栏或增加装饰性图形。

## 验证与完成条件

确定性测试检查指标、转义、敏感值、路径越界/符号链接、缺失证据及错误工具记录。真实 API 导出与 Web 结果一致。实际下载并打开自包含 HTML，截图可见、内部证据链接可用；记录样本与限制，不将合成边界样本当成真实业务执行。

## 完成记录

实际证据见 [报告验证记录](../m4-reports-verification.md)。44 项测试、类型检查、Web 构建通过；5 份真实历史执行导出共 523 项证据、18 张截图，统计与 API 一致。在线预览、目录/证据锚点、下载已实际操作，用户明确确认本地文件截图与证据正常。Windows 延后，有限恢复和中断仍待专项。
