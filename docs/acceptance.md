- [x] C03 自动登录成功、错误密码、失效登录状态有分别可观察的结果。M3 实际登录成功与错误密码暂停；M4 真实提交撤销会话后回到登录页，当前 ERROR、后续 PENDING，显式继续后下一条重新登录并通过。仅限本机可控样本。
- [x] C04 普通图片验证码在目标样本上验证识别与重试，报告成功率/失败情形，不泛称全部支持。限定本机随机六位英文字母/数字图片：8 次可读识别正确 8/8，正常/失效刷新 3 次运行均登录并通过；持续拒绝 3 次提交后暂停，不可读图片观察 3 次、0 提交后暂停。服务限制次数、旧图重用与旧错误提示，截图不含凭证。样本小，不能推断真实系统成功率，见 [专项记录](m3-image-captcha-verification.md)。

- [x] D11 进程退出后保留已有结果，将活动任务标为中断，不自动重放步骤。独立真实执行子进程正常关闭/突然退出后均为 PASSED、INTERRUPTED、PENDING；首条结果逐字段保留，已发出步骤为 UNCERTAIN，第三条没有开始事件。重开历史 API/报告不推进，旧任务不能继续；残留工具存活时阻止新任务，释放后核对并回收匹配锁。仅限 macOS 可控目标，见 [中断记录](m4-interruption-verification.md)。
- [x] D12 没有额外自动清理测试数据；用例明确要求的清理动作有执行记录。两种中断场景创建 1 次、清理 0 次、记录保留；独立明确清理用例真实点击创建及清理，逐项验证当前 0、清理 1、可恢复 1，整条 PASSED，保留 UI 工具与截图证据。仅清理本次可恢复合成记录，未永久删除用户数据。

## F. P0 验收方式

1. 状态转换、统计、导入确认等确定性规则使用有边界意义的单元/契约检查。
2. 用可控页面覆盖通过、失败、阻塞、定位失败、字段顺序、暂停停止等执行场景。
3. 至少连接一个用户指定的真实测试环境，对已确认 Excel 用例完成一批真实执行。
4. 明确记录实际模型/SDK/MCP/浏览器版本、选择的用例和截图。
5. mock 或受控页面验证与真实环境验证分别报告，不将任何一项冒称为另一项。
