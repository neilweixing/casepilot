## 已实现

- React 19.3.1 + Vite 8.3.5 工作台；视觉参考用户已登录的 claude.ai 页面，采用白色主区、浅灰侧栏、简洁字体和细边框。
- 统一自绘下拉组件使用 `@radix-ui/react-select@2.4.1`，覆盖用例集、环境、工作表列映射、所属系统和验证码方式。
- ExcelJS 4.4.0 读取 xlsx，检查压缩目录及大小，不计算公式，不执行宏、外链或工作簿内容。旧版 xls、加密文件、超出预算的工作簿明确拒绝。
- 表头别名、列序变化、说明行、多工作表、单元格多行、合并跨行，保留每条原始行号与完整行文本。
- 预览与人工修订、选择工作表、映射建议/手动映射、拆分/合并、排除、重复编号确认、不可变确认版本。修改必须产生新 revision。
- SQLite 保存草稿、版本、系统和环境；密码/测试验证码使用 AES-256-GCM 加密，密钥位于受限本机目录。响应不返回原始密码、验证码或 credentialRef。
- `pnpm dev` 已配置前端自动更新和后端 watch；`pnpm build` + `pnpm start` 提供单端口构建页面。热加载新入口需用户下次启动后生效，本次未自动替用户重启服务。
- Windows 分支增加 CIM 进程读取、icacls 目录权限和 IPC 终止检查；跨平台测试脚本不依赖 shell 通配符。CI 包含 Windows/macOS、Node 22.19.0/26.12.1，尚未触发运行。
