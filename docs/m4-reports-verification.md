日期：2026-10-30。状态：本机可控样本的报告小阶段已验证，完整 P0 未完成。
Windows 实机验证按用户要求延后；本轮不改变跨平台支持要求。

## 实际修改

- 执行报告列表提供“查看报告”和“下载 HTML”，两者使用同一个服务端渲染函数。文件名带任务 ID，避免混淆不同批次。
- 导出包含确认版本、环境、模型、起止时间、原始来源、前置条件、步骤、逐项结果、任务事件及已登记的工具/观察/截图证据。
- 目录与证据使用文档内锚点。步骤证据按需展开；原始工具内容折叠保存，截图真实内嵌到 HTML。
- 统计仍由共享契约计算，没有新增模型统计或归因请求。执行说明、Agent 记录的逐项观察和原始工具内容分别呈现；未独立确认根因时明确说明。
- HTML 转义所有输入，禁止脚本与外部资源。再次脱敏正文与原始证据；敏感字段如 Cookie、Authorization、token、password 递归遮罩。
- 报告与单项证据接口共同限制真实文件路径，拒绝越界、符号链接绕过、跨任务证据和无效图片。文本证据接口读取时同样再次脱敏。缺失文件有明确提示，不改变原有业务结论。
