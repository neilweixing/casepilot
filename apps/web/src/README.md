# Web 工作台

使用 React 19.3.1、TypeScript、Vite 8.3.5，依赖已精确锁定。`main.tsx` 实现本阶段页面，`Select.tsx` 统一下拉行为与样式。
导入、确认和环境配置已做本机浏览器验证；通用任务与报告页面仅提供后续入口，不用假结果填充。
用户运行 `pnpm dev` 后使用前端 4311 / 后端 4310 的热加载模式；构建页面由 `pnpm build`、`pnpm start` 提供。

页面范围：环境管理、Excel 导入确认、任务列表与详情、报告查看和下载、扩展启用状态。
任务页面发起执行，不用聊天替代确认流程。API key 和密码不下发到前端页面状态或事件流。

参见 [P0 需求](../../../docs/p0.md) 与 [技术设计](../../../docs/architecture.md)。
